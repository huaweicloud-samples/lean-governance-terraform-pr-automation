# 华为云 Terraform PR 自动化工具 — 架构说明

## 工具定位

本工具是一个**配置驱动、与云厂商无关的** Terraform 基础设施更新自动化工具。它读取一份 `config.yaml`，对指定的多个 Terraform 仓库进行参数级修改（升级模块版本、调整资源规格、更新安全组规则描述等），自动创建分支与 Pull Request，并以丰富的通知汇报结果。

工具核心只做三件事：**解析 HCL**、**调用 `terraform fmt`**、**通过 GitHub API 创建 PR**。它本身不依赖任何云厂商 SDK，因此可直接用于华为云 Terraform（`huaweicloud_*` provider）仓库，解析逻辑无需改动——这也是它非常适合作为「华为云最佳实践」沉淀的原因。

## 华为云架构

```
┌────────────┐ 触发 ┌─────────────────────────────────────┐
│ 开发者 │ ─────────▶ │ 华为云 CodeArts 流水线 (手动/定时触发) │
│ (手动/定时) │ │ 构建环境: Python 3.9 + Terraform CLI │
└────────────┘ └───────────────┬─────────────────────┘
│ 构建环境: Python 3.9 + Terraform CLI
▼
┌──────────────────────────────────┐
│ src/main.py (配置驱动引擎) │
│ - 读取 config.yaml │
│ - HCL 解析与参数级更新 │
│ - terraform fmt │
│ - GitHub API 创建分支 / PR │
└───────┬───────────────────┬───────┘
│ │
▼ ▼
┌──────────────────────┐ ┌──────────────────────────┐
│ 目标 Terraform 仓库 │ │ 通知 / 产物 │
│ (GitHub 上的 │ │ - SMN 主题 (原生通知) │
│ huaweicloud_* 配置) │ │ - OBS 桶 (日志 / 产物) │
└──────────────────────┘ └──────────────────────────┘
```

## 组件与华为云服务对照

| 能力 | 华为云实现 | 说明 |
| --- | --- | --- |
| CI 运行时 / 触发器 | **CodeArts 流水线** | 提供临时构建机 |
| 可选通知 | **SMN 主题** | 原生消息通知；富文本消息以纯文本/JSON 形式发送 |
| 日志与产物 | **OBS 桶** | 运行日志与产物落盘 |
| 建 PR 所用凭证 | GitHub Token + CodeArts 密钥 / DEW | 建 PR 使用 GitHub Token；华为云侧可用 CodeArts 密钥或 DEW 托管凭证 |
| 演示目标 | `huaweicloud_*` 资源 | 工具 provider-agnostic，示例配置使用华为云资源 |

## 关键设计点

- **Git 交互层**：工具通过 GitHub API 创建 PR；`TerraformVersionUpdater` 的 Git 交互层也可对接 CodeArts Repo API。
- **通知**：华为云 **SMN** 主题作为原生通知通道，可与 Webhook 通知同时启用。
- **产物**：使用 **OBS** 桶存放日志与输出。
- **执行环境**：**CodeArts 流水线**提供临时构建机，免去常驻计算资源。

## 已知依赖与限制

工具零云 SDK 依赖，通知能力通过 SMN 主题原生提供。运行期无需常驻计算资源，执行环境由 CodeArts 流水线按需提供。
